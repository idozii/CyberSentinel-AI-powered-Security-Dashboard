# CyberSentinel-AI-powered-Security-Dashboard

## Goals:
Building AI-powered system to detect phishing attemps, brute force, DDoS with Dashboard Visualization

## Tech Stack
- Backend: FastAPI
- Frontend: React
- ML Model: Isolation Forest / Autoencoder
- Database: PostgreSQL + Elasticsearch
- Container: Docker

## Datasets:
- CICIDS2017: https://www.unb.ca/cic/datasets/ids-2017.html
- NSL-KDD: https://www.unb.ca/cic/datasets/nsl.html
- Honeypot logs: self-generated
